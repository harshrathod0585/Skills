# Skills

A collection of Claude Code skills, one folder per skill.

## Skills

- [`auto-gear/`](auto-gear/) — hard ceiling on which Claude model subagents may use, plus cost-based task routing. See [auto-gear/README.md](auto-gear/README.md).
- [`eval-pipeline/`](eval-pipeline/) — design, build, and run evaluation pipelines for LLM-powered applications (RAG, agents, chatbots, tool-using workflows).

## Adding a skill

Add a new top-level folder with a `SKILL.md` (and any supporting files), following the layout of the existing skills.
